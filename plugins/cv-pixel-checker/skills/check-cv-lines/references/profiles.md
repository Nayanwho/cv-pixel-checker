# CV layout profiles

Use the profile matching the source section. Explicit `maxWidthPx` overrides are appropriate when the user's template differs.

| Profile ID | Typical section | Width |
|---|---|---:|
| `PROJECT_DETAILS` | Project, internship, or work-detail rows without a year column | 599 px |
| `PROJECT_ACHIEVEMENTS` | Achievement rows without a year column | 599 px |
| `POR_WITH_YEAR` | Positions of responsibility with a year column | 559 px |
| `EXTRA_CURRICULAR_WITH_YEAR` | Competitions and activities with a year column | 559 px |
| `ACADEMIC_WITH_YEAR` | Academic achievements with a year column | 677.67 px |
| `CERTIFICATIONS` | Certifications and licences | 677.67 px |
| `PROJECT_TITLE_ROW` | Full-width title or section-header row | 720 px |

Legacy aliases remain supported: `preset_internship`, `preset_por`, `preset_extracurricular`, `preset_academics`, and `preset_standard`.

Defaults use EB Garamond at 9.75 pt, regular weight 400 and bold weight 700. The default target band is 98–100% utilisation.
